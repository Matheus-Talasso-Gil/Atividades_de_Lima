## Resolução

### Exercício 1 — Sintaxe do CSS

- **Seletor:** `h1`, que seleciona os títulos de nível 1.
- **Propriedade:** `color`, que define a cor do texto.
- **Valor:** `red`, que aplica a cor vermelha.

O CSS define a aparência dos elementos HTML, como cores, espaçamento e fontes. Na regra apresentada, o texto de todos os elementos `h1` fica vermelho.

### Exercício 2 — Página estilizada

A página [index.html](index.html) contém um título e dois parágrafos. O arquivo [style.css](style.css) aplica fundo cinza claro (`lightgray`), título azul (`blue`) e texto preto (`black`).

A mesma página apresenta a empresa fictícia **Lima Soluções Digitais**, descreve seus serviços e informa um e-mail ilustrativo para contato. A fonte Arial facilita a leitura.
